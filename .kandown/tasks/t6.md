# Implement PRD phase 1 Astro rebuild

## Context

Rebuild `vavanessa.dev` from the current Next.js waiting page into the Astro 5 architecture described in `PRD-vavanessa-dev.md`.

Decision for phase 1:
- English is the default editorial language.
- Keep content schema ready for future `fr` and `zh` translations, but do not build a full multilingual routing system yet.
- Remove the current Next.js app surface while preserving project docs, Kandown files, PRD, and inspiration assets.

- [x] Read project instructions and PRD.
  report: Read `AGENTS.md`, `README.md`, `.kandown/AGENT_KANDOWN.md`, and `PRD-vavanessa-dev.md`; confirmed the target Astro 5 phase 1 scope.
- [x] Remove the existing Next.js waiting-page implementation.
  report: Removed the Next.js `app/`, shared waiting-page component folders, Next config files, generated `.next/` output, and default public SVG assets while preserving docs, PRD, Kandown files, and inspiration assets.
- [x] Configure Astro 5, TypeScript strict mode, Tailwind CSS v4, MDX, sitemap, and RSS.
  report: Replaced the Next.js package scripts and configs with Astro 5, strict TypeScript, Tailwind CSS v4 through Vite, MDX, sitemap, RSS, and Fontsource. React was intentionally deferred to the later interactive demos phase to avoid unnecessary client JavaScript.
- [x] Create content collections for posts and projects with strict Zod schemas.
  report: Added `src/content/config.ts` with validated post and project schemas, including English-first `lang` support that can later accept French or Chinese translated entries.

  report: Added shared header/footer components, `BaseLayout.astro`, `PostLayout.astro`, and `ProjectLayout.astro` with canonical links, OG/Twitter metadata, and JSON-LD for Person, BlogPosting, and SoftwareApplication.

  report: Added home, blog index, blog detail, tag archives, projects index, project detail pages, RSS, and static about/now/uses/newsletter placeholders.

  report: Added one public launch note, one draft validation post, and six project entries for Kandown, ModelRadar, free-coding-models, Pylz, Out Of Burn, and nexTTY.

  report: Replaced the default Next.js README with Astro project documentation, added `CHANGELOG.md`, and updated `.gitignore` for Astro build artifacts.

  report: Ran `pnpm build`; Astro check and production build completed with 0 errors, 0 warnings, and 0 hints. Also verified key local routes with `curl -I`.
