# Add light dark auto theme support

## Context

Add light, dark, and auto color mode support to the Astro site. Auto should be the default and should follow the system preference. Keep the implementation aligned with Tailwind CSS v4 and shadcn-style CSS variables without adding React just for this static control.

## Subtasks

- [x] Read project instructions and theme-related files.
  report: Read `AGENTS.md`, `README.md`, `.kandown/AGENT_KANDOWN.md`, shadcn guidance, `BaseLayout.astro`, `Header.astro`, and `global.css`.
- [x] Add shadcn-compatible theme tokens and mode switching script.
  report: Added Tailwind v4 `@theme inline` mappings for shadcn-style semantic tokens, light/dark CSS variables, a `.dark` variant, `components.json`, and an early inline layout script that defaults to `auto`.
- [x] Add a header theme selector for light, dark, and auto.
  report: Added `ThemeToggle.astro` and mounted it in the header. It persists `light`, `dark`, or `auto` in localStorage, follows system color changes in auto mode, and updates pressed state plus theme color metadata.
